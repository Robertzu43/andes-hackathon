## Infrastructure handoff

Exact environment/commands and schema exports are documented in `docs/contracts/runtime.md` and `.env.example`.

- Build `npm ci && npm run build`; one-off `DATABASE_URL=... npm run migrate`; API `npm start`; ECS commands `npm run worker:control`, `npm run worker:emergency`, `npm run worker:ordinary`.
- Workers require `DATABASE_URL`, `AWS_REGION`, `SQS_EMERGENCY_URL`, `SQS_ORDINARY_URL`, task-role credentials. Control needs SendMessage; each consumer needs ReceiveMessage/DeleteMessage/ChangeMessageVisibility only for its class queue. Separate Standard queues/DLQs. No automatic DLQ resend path.

Callback can run with complete context while new sends are disabled. Production loading rejects test syntheticfixture evidence. A manifest's evidence references are operator assertions requiring actual verification.
